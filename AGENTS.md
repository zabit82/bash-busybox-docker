# Инструкции для AI-агентов

В данном репозитории действует обязательное правило: **всегда использовать базу знаний Obsidian через MCP**.

## Основные правила

1. **Консультация с базой знаний**:
   - Перед началом любой задачи изучить глобальные правила в `Главные правила разработки.md` в Obsidian.
   - Ознакомиться с контекстом проекта в `context/bash-busybox-docker.md`.
   - Ознакомиться с архитектурой файлов в `structure/bash-busybox-docker.md`.
2. **Планирование**:
   - Всегда строить план действий перед внесением изменений.
   - Никогда не коммитить в git без явного разрешения пользователя.
3. **Журналирование изменений (`daily-changes`)**:
   - Все действия и этапы выполнения задачи обязательно фиксировать в файле `daily-changes/bash-busybox-docker/<YYYY-MM-DD>.md` с указанием таймштампов (`[HH:MM:SS]`).
4. **Синхронизация документации**:
   - При добавлении, изменении или удалении файлов актуализировать `structure/bash-busybox-docker.md` и `context/bash-busybox-docker.md`.
5. **Комментарии в коде**:
   - При внесении правок в `Dockerfile`, CI/CD или скрипты всегда оставлять понятные комментарии с объяснением того, что и зачем изменено.
